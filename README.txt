🧬 DNA Sequence Analyzer — MATLAB

A simple bioinformatics project developed using MATLAB to analyze DNA sequences and extract basic biological information.

📌 Project Overview

DNA consists of four nucleotide bases:

- A — Adenine
- T — Thymine
- G — Guanine
- C — Cytosine

This project accepts a DNA sequence as input and performs basic sequence analysis. It demonstrates how MATLAB can be used for computational analysis in biotechnology and bioinformatics.

✨ Features

- 🔬 Accepts a DNA sequence as input
- 📏 Calculates DNA sequence length
- 🔢 Counts A, T, G, and C nucleotides
- 🧪 Calculates GC content
- 🧪 Calculates AT content
- 📊 Displays analysis results
- 📈 Provides graphical visualization of nucleotide composition
- ✅ Checks whether the input contains valid DNA bases

🧮 Calculations

GC Content

GC content represents the percentage of Guanine and Cytosine bases in the sequence.

GC% = (G + C) / Total Bases × 100

AT Content

AT content represents the percentage of Adenine and Thymine bases.

AT% = (A + T) / Total Bases × 100

▶️ How to Run

1. Open MATLAB or MATLAB Online.
2. Download or clone this repository.
3. Open "DNA_Sequence_Analyzer.m".
4. Run the program.
5. Enter a valid DNA sequence containing:
   "A", "T", "G", and "C".
6. View the calculated results and visualization.
